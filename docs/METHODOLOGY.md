# Methodology

Everything here is computed from settled Korea Exchange sessions. No intraday snapshots, no
vendor-estimated values, no back-filled gaps.

## Investor flows

**Universe.** 2,555 KOSPI and KOSDAQ common stocks. SPACs, ETFs, REITs and preferred shares
are excluded. The universe is a fixed list refreshed from the KRX issue master, so a stock
does not silently enter or leave the series at the moment it becomes newsworthy.

**Source unit.** Net buying arrives as a **share count** per stock, per session, per investor
class (foreign / institution / individual).

**Valuation.** Every KRW or USD figure is derived:

```
value(period) = Σ over sessions [ net_shares(session) × settled_close(session) ]
```

Each day's shares are valued at **that day's** close, then summed — never at a single
period-end price. In a week containing a −14.65% session and a +29.95% session the two
methods differ by roughly 20%. This is not a rounding detail; it is the difference between
two answers.

**Windows.** `1d` = the latest settled session · `5d` = 5 sessions · `20d` = 20 sessions.
All windows count **trading sessions**, never calendar days, so they align with the exchange
calendar and with each other.

**Currency.** USD figures use the rate carried in each file's own `meta.usd_krw`, applied to
the whole file. Comparing two files from different dates means comparing two rates; the FX
move between them is real, and mixing rates silently is an error we have made and corrected.

**Individual (retail) flows** are collected for 27 large-cap tickers only. They are not in the
published files, and no market-wide retail figure should be inferred from this dataset.

**Known limitation.** These are approximations of traded value — we do not have execution
prices. Against the reported settled market-wide foreign net for 24 July 2026 (−₩3.2828tn),
summing this dataset over the same session gives −₩3.2796tn, a **0.1%** difference. Expect
that order of accuracy for liquid names and less for very illiquid ones.

## Sector indices

**Source.** KRX Open API official index series (`idx/kospi_dd_trd`, `idx/kosdaq_dd_trd`),
which returns settled sessions only — an unpublished day comes back empty rather than
half-formed, so an intraday value cannot masquerade as a close.

**What counts as a sector.** Market, size, strategy and thematic indices are filtered out
(KOSPI 200, large/mid/small cap, dividend, value, momentum, ESG, leverage, inverse, board
memberships). The broad "Manufacturing" index is also excluded because it aggregates several
sectors and distorts sector-versus-sector comparison. What remains is 44 sector indices
across the two boards.

**Returns.**

| Field | Definition |
|---|---|
| `return_1d_pct` | the exchange's own published change rate for the session |
| `return_1w_pct` | 5 trading sessions |
| `return_1m_pct` | 21 trading sessions |
| `return_ytd_pct` | first session of the calendar year |
| `excess_1m_vs_market_pp` | `return_1m_pct` minus the sector's own board benchmark (KOSPI or KOSDAQ), in percentage points |

**Time series** (`series` in the JSON) is every index rebased to 100 at the first session of
the year, at 3-decimal precision, with no sampling. Both properties matter: a chart that
re-bases these values to a shorter window amplifies rounding error, and a sampled series
breaks the session-count alignment the return windows depend on.

**Sector names** are given in English and Korean. The Korean name is the join key back to any
KRX source, so it is carried in every row rather than translated away.

## What this dataset is not

- **Not a redistribution.** Derived aggregates and returns only, not a mirror of any vendor feed.
- **Not adjusted.** Closes are as settled; no dividend or split adjustment is applied.
- **Not investment advice.**

## Provenance and corrections

Generated by scripts in a private repository, published to `https://kexportstars.com/data/`
every trading day at ~02:00 KST and mirrored here, with a dated snapshot under `archive/`.

Corrections are logged publicly at https://kexportstars.com/about/ rather than applied
silently — including corrections to this dataset's own past figures. Two we have already
published, both listed above as traps because we walked into them ourselves: valuing a week's
flows at one price instead of daily closes, and quoting a 9:53 a.m. intraday figure that was
four times smaller than the settled session. If you find another, open an issue.
